# tammersaleh/homebrew-tap

Personal Homebrew tap. macOS only (casks are not supported on Linux).

## Install

    brew install tammersaleh/tap/<cask>

## Casks

- `tammersaleh-slack-cli` - https://github.com/tammersaleh/slack-cli (renamed from `slack-cli`, which collides with homebrew/cask)
- `confluence-cli` - https://github.com/tammersaleh/confluence-sync
